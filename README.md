# 📧 Spam Email Detection System

An AI-powered Spam Email Detection System built using Machine Learning and Natural Language Processing (NLP).  
This project classifies emails/messages as **Spam** or **Not Spam (Ham)** using Python, Scikit-learn, and Flask.

---

## 🚀 Features

- Detects spam emails/messages instantly
- NLP-based text preprocessing
- Machine Learning classification model
- Clean and simple Flask web interface
- Model saved using Pickle
- Easy to train with custom datasets

---

## 🛠️ Technologies Used

- Python
- Scikit-learn
- Pandas
- NumPy
- NLTK
- Flask
- HTML/CSS
- Pickle
